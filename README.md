# Memory Guardian

HAIMEZ 제작.

Memory Guardian은 Windows 메모리 사용 패턴을 학습하고 RAM, 커밋 메모리, Non-Paged Pool, 프로세스 증가량을 분석하는 메모리 진단 도구입니다.
