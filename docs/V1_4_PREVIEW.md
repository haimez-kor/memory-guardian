# 1.4.0 구현 범위

## 적용
- 장기 추세 종료 날짜/시각, 기간 조회, 이벤트 목록 검색/정렬/상세 표시.
- 기존 설치 폴더의 기록 읽기 전용 조회 및 폴더 선택. 원본 기록은 수정하지 않음.
- 그래프와 이벤트의 가로축을 실제 경과 시간 기준으로 통일.
- 중립색 다크/라이트 테마, 표와 컨트롤 정리, 대시보드 스크롤.
- 게임 이름 부분 일치 제거. 알려진 게임 실행 파일과 전면 창 PID를 함께 확인. Steam 런처, 보조 프로세스, 일반 Java 제외.
- 게임 감지 전환 시 로그 기록. 같은 게임의 분당 정리 보류 로그 제거.
- Java/Chrome/Edge는 GC·힙 정보 없이 누수로 단정하지 않고 지속 증가 관찰로 분류.
- 현재 점수와 별도로 툴팁에 5분 시정수 평활 참고 점수 표시.
- 자체 정리 API 시간, 기준 RAM/커밋/작업 집합, 1분·5분 후 변화를 이벤트에 기록.

## 한계
- GPU/CPU 부하 기반 게임 판별, GC 수집, 프로세스별 학습 모델은 미구현.
- 평활 점수는 장기 건강도 모델이 아님.
- FPS/프레임 지연, 정리의 인과적 성능 효과는 측정하지 않음.
- 정리 후 관측은 실행 중에만 수행되며 앱 재시작 시 이어지지 않음.
- 정식 변경 사항은 RELEASE_NOTES_1.4.0.md를 참고하세요.
