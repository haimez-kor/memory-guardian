# 오류 로그 전송 고지

Memory Guardian은 크래시 또는 비정상 종료가 의심되면 다음 실행 시 사용자에게 오류 로그 전송 여부를 먼저 묻습니다.

사용자가 직접 동의하지 않으면 어떤 오류 정보도 전송하지 않습니다.

## 전송 대상

```text
https://mg.haimez.kr/api/error-reports
```

## 전송되는 정보

- 오류 코드
- 앱 버전
- 사용자가 직접 입력한 연락처
- 사용자가 직접 입력한 오류 요약
- 사용자가 직접 입력한 상세 설명
- Windows 버전
- CPU 아키텍처
- 논리 코어 수
- 전체 RAM 용량
- 현재 RAM 사용률
- 현재 사용 중인 RAM
- 커밋 메모리
- 페이지 파일 사용량
- Non-Paged Pool
- Paged Pool
- 관리자 권한 실행 여부
- 사용 모드
- 최근 앱 내부 로그 일부

## 전송하지 않는 정보

- 파일 내용
- 개인 문서
- 브라우저 방문 기록
- 키 입력
- 비밀번호
- 브라우저 탭 제목
- 환경 변수
- 명령줄 인자
- 전체 파일 경로
- 사용자 폴더 경로

## 사용 목적

전송된 오류 로그는 Memory Guardian의 크래시, 오류, 업데이트 문제, 호환성 문제를 분석하고 수정하기 위해 사용됩니다.

오류 로그 전송은 선택 사항이며, 사용자는 언제든지 전송하지 않을 수 있습니다.
